btop 速查手册

btop 是资源监控界的「瑞士军刀」——一个窗口同时看清 CPU、内存、网络、磁盘和进程，支持鼠标操作和主题换肤。

安装：brew install btop

第一次打开：你会看到什么

┌──────────────┬──────────────┐
│   CPU 图表    │   内存 + Swap │  ← 上面：资源总览
├──────────────┼──────────────┤
│  网络收发图   │   磁盘读写图  │
├──────────────┴──────────────┤
│                             │
│        进程列表              │  ← 下面：所有进程
│   PID  NAME  CPU%  MEM%     │
│   123  node   45%   200M    │
│                             │
└─────────────────────────────┘

颜色含义：绿色 = 健康，黄色 = 注意，红色 = 紧张，蓝色 = 空闲。

可以用鼠标：点击进程选中，滚轮翻页，拖拽列宽。

四个最常用场景（跟着做）

场景一：电脑变卡了，找出谁在吃资源

步骤 1：启动 btop，看进程列表最上方——默认按 CPU 排序，占用最高的在最前面。

步骤 2：如果列表太长，按 f 输入进程名过滤（比如输入 chrome），回车确认。

步骤 3：看到目标后，按 delete 清除过滤。按 ← → 切换排序列（CPU / 内存 / PID / 名称），按 r 反向排序。

示例：

按下 f → 输入 node → 回车
只看到名字带 node 的进程
按下 delete → 恢复显示全部
按下 → 两次 → 切换到按内存排序
按下 r → 从大到小排（或从小到大）

场景二：关掉一个卡死的程序

步骤 1：在进程列表中找到目标，按 ↑ ↓ 选中它。

步骤 2：按 k，会弹出确认框，再按一次 k 或 Enter 发送终止信号（SIGTERM）。

步骤 3：如果程序没反应，再按一次 k 选择更强制的信号（SIGKILL），回车确认。

示例：

选中 node (PID 8845) → 按 k → 程序退出
如果没退出 → 再按 k → 选 SIGKILL → 回车 → 强制结束

场景三：换一套顺眼的配色

步骤 1：按 m 打开菜单。

步骤 2：按 ↓ 选中 Color theme，回车。

步骤 3：方向键挑选（推荐 Dracula 或 Nord），回车确认，按 Esc 退出菜单。

示例：

按 m → 按 ↓↓ 到 Color theme → 回车
按 ↓ 选 Dracula → 回车 → 按 Esc
界面立即变色

场景四：用进程树看父子关系

步骤 1：在进程列表中按 e 切换到树形视图。

步骤 2：用 ↑ ↓ 选中一个进程，按 Spacebar 展开或折叠它的子进程。

步骤 3：按 C 一次性展开或折叠当前进程的所有子孙进程。

示例：

按 e → 进程列表变成树形
选中 Terminal → 按 Spacebar → 展开看到 zsh、node 等子进程
按 C → 一次性展开/折叠当前分支的所有子孙
按 e → 切回普通列表

预设是什么

预设就是「面板组合」。btop 允许你在配置中定义最多 10 种不同的面板排法，然后按 p 和 shift + p 循环切换。

默认预设的几个示例：

预设 布局内容 用途
默认 全部面板 第一次用，想看全局
预设 1 CPU 放右边，进程放左边 进程列表更宽
预设 2 CPU + 内存 + 网络 隐藏磁盘和进程，纯看资源趋势
预设 3 CPU(方块图) + 网络(兼容字符) 终端字体不支持盲文时用

切换方式：p 向前循环，shift + p 向后循环。

保存自定义预设：按 m 打开菜单 → 调整 shown_boxes 等选项 → 修改配置文件中 presets 那一行。预设修改需要编辑配置文件，不是按某个快捷键就能存的。

进程列表各列含义

  PID       NAME       CPU%    MEM%    TIME    THRDS   USER
  123      node         45%    200M    02:34     12    carl
列 含义
PID 进程编号（系统唯一标识）
NAME 程序名字
CPU% 当前占用多少 CPU
MEM% 当前占用多少内存
TIME 累计运行时间
THRDS 线程数
USER 哪个用户启动的

按 e 可以切换成进程树，看到父子关系（比如终端 → shell → node）。

常见问题：如果你遇到…

界面花屏，全是方块？

你的终端字体不支持盲文符号。按 m 进入菜单，把 Graph symbol 改成 block（方块）或 tty（极简）。

Apple Silicon 看不到 GPU？

正常。btop 在 macOS 不支持 Apple Silicon GPU 监控，这是系统限制，不是 bug。

按了 k 进程没消失？

第一次按 k 是「礼貌请求退出」（SIGTERM）。如果程序顽固，再按一次 k 就能选 SIGKILL（强制拔掉电源）。

进程名字被截断？

用鼠标拖拽列宽，或者切换预设让进程区更宽（按 p 循环到进程区放左边的布局）。

核心按键（先记住这 7 个）

按键 场景
f 搜进程
k 关进程
← → 切换排序列
r 反向排序
e 看进程树
m 改设置
q 退出

其他的，随用随查这份文档即可。
